# lhg-lr-write：综述逐节写作方法论

> 目标：写出"有观点"的综述，而不是文献摘抄合集。
> 核心纪律：**每节"主题句 + 证据 + 评价"三段式；评价不许只说好话，必须指出分歧与不足。**

## 1. 何时使用

- 大纲已冻结、开始写正文 → 逐节调用
- 某节写完导师批"像教科书" → 按第 4 节返工评价段
- 引言/批判/展望三节卡壳 → 直接看第 3 节的特殊写法

## 2. 输入与输出

**输入**：`综述框架.md` 中某一节（标题 + 要回答的问题 + 拟引文献编号）。

**输出**：该节成稿 Markdown（800~2000 字/节为宜），文内引用编号与文献池对应。

## 3. 分步方法论

### 3.1 每节三段式

1. **主题句（1~2 句）**：开门见山讲清本节论点。好例子："自动评分研究经历了从规则模板到神经网络再到大语言模型的两次范式转移，每次转移都由'评价维度'的扩展驱动。"坏例子："本节介绍自动评分的相关研究。"（后者等于没说）
2. **证据（主体）**：按时间或逻辑组织文献，组织方式三选一——
   - 编年：适合演进脉络（"2019 年 X 首次…；2022 年 Y 改进…"）
   - 归类：适合观点分歧（"支持 A 的有…[2][5]；质疑 A 的有…[7]"）
   - 递进：从简单到复杂、从实验室到真实场景
   - 每处观点后紧跟引用编号。转述不许改变原意，关键数据（样本量、效应值）保留原值并注明出处。
3. **评价（收尾段，必备）**：回答"这一节看完，我们知道了什么、还不知道什么"。至少包含一句批判：证据强度如何、有没有反例、方法上有何局限。没有评价段的节，一律退回。

### 3.2 引言：漏斗式四段

1. 大背景（一句话）：这个领域为什么重要
2. 具体问题（2~3 句）：聚焦到本综述的问题，可引用 1~2 篇奠基性文献
3. 为什么需要这篇综述：已有综述的不足（如"已有综述多截至 2022 年，未覆盖大语言模型时代"）——这是你这篇综述的合法性来源
4. 本文结构（一句话带过）：第 2 节…第 3 节…第 4 节批判…第 5 节展望

引言不许出现大段文献罗列，那是主体节的事。

### 3.3 批判性述评：共识 / 分歧 / 短板

- **共识**：2~3 条，用"多项研究一致表明…"句式，每条带 3 个以上引用
- **分歧**：讲清分歧点在哪（如"评价指标不统一：A 用二次加权 kappa，B 用 Pearson 相关，导致结果不可比"），不许只说"存在分歧"
- **短板**：具体到方法论层面，如"样本多为英语议论文，中文场景仅 2 篇实证""缺乏纵向追踪设计""开源复现率低"。短板越具体，展望节越好写

套话黑名单（出现即重写）："学者们做了很多有益探索""取得了丰硕成果""仍有待进一步深入"——这些等于没说。

### 3.4 研究展望：三句话方向

每个未来方向写满三句：**做什么**（具体研究问题）→ **为什么值得做**（承接批判节的短板）→ **难在哪**（数据/方法/伦理上的挑战）。3 个方向为宜，贪多嚼不烂。

### 3.5 学术中文表达规范

- 一句话只讲一件事，主语明确；禁用"众所周知""不言而喻"
- 数字与单位：样本量、年份、百分比用阿拉伯数字，句首不用数字开头
- 引用动词分级：支持类（表明/证实/支持）vs 转述类（指出/认为/报告）vs 质疑类（质疑/反驳/指出局限）——动词本身就是你的评价
- 段落长度：一段 150~300 字，一段超过 400 字就拆
- 直接引用（加引号）只用于关键定义/论断，且尽量注明页码；全文直接引用不超过 3 处

### 3.6 段落写作模板（含示例）

**观点归类段**（最常用的段式）：

> 主题句：在自动评分的评价指标上，研究者存在明显分歧。证据：以二次加权 kappa 为指标的研究多报告乐观结论[2][5]，而采用人评一致率的研究则更为谨慎[7]，这种差异可能源于指标本身对"相邻误判"的容忍度不同。评价：指标不统一导致跨研究比较困难，也是该方向证据强度评级不高的直接原因。

检查：主题句（一句话论点）✓、证据（3 个引用，分正反两面）✓、评价（指出后果）✓。缺任何一段，这个段落就是半成品。

**转折段**（节与节之间用）：上一节讲了 A，这一节讲 B，用一句话交代逻辑关系，如"评分解决的是'判得准不准'，而反馈生成要回答的是'评完之后怎么办'——后者是前者的自然延伸。"没有转折句的节与节，就是拼接。

### 3.7 转述的四种手法与查重红线

1. **换句式**：主动变被动、长句拆短句，意思不变
2. **换角度**：原文讲"方法"，你转述为"结论"（如原文"我们用 X 方法得到 Y"，转述为"X 方法能得到 Y[3]"）
3. **压缩**：三段论证压缩成一句，保留核心数据
4. **综合**：把 2~3 篇文献的相似发现合成一句，引用并列（如"…在多个场景得到验证[2][5][8]"）

**查重红线**：连续 13 个字与原文相同即可能被标红——转述后自己读一遍，凡是"这句话像是从原文抄的"，一律重写。关键术语、专有名词、数据除外（这些不算抄袭，但要规范引用）。

### 3.8 初稿后的三轮修改法

不要指望一遍写好，按三轮改，每轮只干一件事：

1. **第一轮（结构轮）**：只看节标题和每段首句。问：逻辑链条通吗？有没有重复的节？评价段都在吗？这轮可以大删大并，不心疼字数。
2. **第二轮（证据轮）**：逐段核对引用。问：每个观点都有引用吗？引用编号对吗？转述忠实原文吗？这轮对照文献池逐条过，顺手跑一遍 `citation_audit.py`。
3. **第三轮（文字轮）**：只改表达。问：有套话吗？段落超长吗？动词分级用对了吗？这轮不许再动结构，否则前两轮白做。

三轮之间至少间隔半天。当天写完当天交，等于只做了零轮修改。

### 3.9 合作写作时的分工建议

两人以上合写综述：按节分工，每人负责 1~2 节；统稿人负责引言、批判、展望三节（最需要全局视角的部分）；开工前统一三件事——引用制、术语译名表（如"large language model"统一译"大语言模型"）、标题层级格式。合稿后必须通读两遍，消除"拼接感"。

### 3.10 评价段句式库（直接套用，按需改写）

- 表共识："多项研究一致表明……[2][5][8]，这一结论在……场景下得到重复验证。"
- 表分歧："但在……问题上存在分歧：A 派以……为据支持……[3]，B 派则基于……提出质疑[7]，分歧的根源在于……。"
- 表短板："现有研究的短板在于……：一是……（如样本局限），二是……（如方法单一），三是……（如缺乏复现）。"
- 表证据强度："综合来看，……方向的证据较为充分，而……方向仅有零星探索，结论需谨慎对待。"
- 收束："以上分析表明，该主题已形成……的基本图景，但……问题仍悬而未决，这正是第 X 节展望的起点。"

**注意**：句式是脚手架，不是填空题。每个省略号都必须填上来自文献的具体内容，填不上说明这一节还没读透，回去重读文献而不是硬套句式。

### 3.11 数字与图表的使用规范

- 综述里的数字全部来自文献，引用紧跟数字之后，如"复现率不足三成[9]"
- 自制汇总表（如"三种技术路线对比表"）是加分项：表头写清对比维度，表注写清数据来源文献编号
- 不许自制"趋势图"然后编数据——没有数据的图不如没有图
- 引用他人图表必须注明出处并获得授权（学位论文通常适用合理使用，但要标注）
- 图表在正文中必须被"点名"（如"如表 2 所示"），出现图表却正文不提及的，删掉图表

## 4. 反模式

- ❌ "作者A研究了X，作者B研究了Y"式流水账——按观点组织，不按作者组织
- ❌ 评价段只说好话——综述的价值在批判，没有批判就没有贡献
- ❌ 转述时偷换概念（把"相关"写成"因果"）——这是学术不端的高危区
- ❌ 引用编号与文献池对不上——写完一节立刻核对，不许攒到最后
- ❌ 在综述里写"本文首次提出"——综述的贡献是梳理与评价，"首次"留给原创研究

## 5. 自检与反馈

每节写完对照打勾：

1. 主题句能否一句话概括本节论点？→ 不能就重写第一段
2. 每个观点后面都有引用编号吗？→ 裸奔的观点全部补引用或删除
3. 收尾有评价段吗？→ 没有就不是综述节，是摘抄
4. 评价段里有具体的批判（分歧点/方法短板）吗？→ 只有套话就重写
5. 转述的关键数据与原文一致吗？→ 存疑的标"待核对原文"，不许脑补
6. 直接引用是否 ≤3 处且都有出处？→ 超了就改转述

标准冒烟用例：检查插件自带的 `fixtures/` 目录结构完整（见仓库根 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-lit-review/issues，正文写清"输入 → 错误输出 → 期望输出"。
