# /lhg-lit-review:lit-review —— 文献综述一条龙

用户输入在 `$ARGUMENTS` 中：`[综述主题] [--style gb7714|apa]`。主题缺省则先问用户；引用风格缺省为 `gb7714`。

## 流程（全程按四个 skill 推进）

### 第 1 步：文献收集（加载 lhg-lr-collect）
1. 与用户界定综述问题：研究对象、时间范围、文献类型（期刊/学位论文/会议/专著）。
2. 共建关键词矩阵（中文词 + 英文词 + 同义词/上下位词），产出检索式。
3. 用户亲手去知网/万方/Web of Science 等库检索（**检索动作由用户执行**，助手不编造"已找到"的文献）。
4. 用户把题录粘回来后，助手按纳入/排除标准做初筛，产出 `文献池.md`（编号、题录、纳入理由、主题标签）。

**硬规则**：绝不编造文献——没有真实题录就写"待补充"，不许杜撰作者、期刊、年份。

### 第 2 步：框架设计（加载 lhg-lr-frame）
1. 按文献池的主题标签做聚类，选三条路线之一：主题聚类 / 时间线演进 / 学派对比。
2. 输出框架大纲（含每节要回答的问题、拟引文献编号），用户确认后再写。

### 第 3 步：逐节写作（加载 lhg-lr-write）
1. 按大纲逐节写：引言 → 主题述评（每节） → 批判性述评 → 研究展望。
2. 每节遵循"主题句 + 证据（带引用） + 评价"三段式；评价不许只说"很好"，必须指出不足/分歧/空白。

### 第 4 步：引用校验（加载 lhg-lr-cite + 跑脚本）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/citation_audit.py --target <稿件目录> --format text
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/structure_audit.py --target <稿件目录> --format text
```
blocker（孤儿引用/僵尸条目/缺著者/缺引言/缺述评）必须清零；warning 写豁免或修复。

## 交付物
- `文献池.md`（去重后的题录 + 筛选记录）
- `综述框架.md`（大纲）
- `综述正文.md`（逐节成稿）
- `自查报告.md`（审计结果 + 豁免清单）

## 硬规则
- 编造一条文献 → 整个交付作废，这是红线。
- 只有罗列没有述评 → 不叫综述，退回第 3 步重写批判节。
- 引用风格全文统一（gb7714 或 apa 二选一），不许混用。
