# /lhg-lit-review:write —— 逐节写作

用户输入在 `$ARGUMENTS` 中：`[大纲文件] [--section <节名>]`。缺省大纲为 `综述框架.md`；不指定节则按顺序逐节写，每节写完请用户确认再继续。

## 流程（加载 lhg-lr-write 全程指导）

### 1. 写前检查
- 大纲是否存在且经用户确认？没有 → 先跑 `/lhg-lit-review:frame`。
- 本节拟引文献是否都在文献池里？不在 → 标"待补充文献"，不许现编引用编号。

### 2. 逐节写作（每节三段式）
1. **主题句**：一句话讲清本节要论证什么（如"自动评分研究经历了从规则模板到神经网络再到大语言模型的范式转移"）。
2. **证据**：按时间或逻辑组织文献，每处观点后紧跟引用编号（如"…显著提升了评分一致性[3][7]"）。转述不许改原意，关键数据保留原值。
3. **评价**：收尾必须有一段"本节小结+批判"——共识是什么、证据强度如何、有什么没解决。

### 3. 特殊节写法
- **引言**：漏斗式（大背景 → 具体问题 → 为什么需要这篇综述 → 本文结构），不许一上来就罗列文献。
- **批判性述评**：用"共识/分歧/短板"三件套；分歧要讲清分歧点在哪（如"样本量""评价指标"），短板要具体到方法。
- **研究展望**：每个方向写"做什么、为什么值得做、难在哪"三句，不许只喊口号。

### 4. 每节交付即确认
每节写完停一下请用户确认（事实准确性由用户把关，助手不背书文献原意）。

## 硬规则
- 引用编号必须与文献池/参考文献一一对应，写完一节就顺手核对。
- 不许出现"本文首次提出""填补空白"这类只有原创研究才配说的话——综述的贡献是"梳理与评价"。
- 转述比例控制：直接引用（加引号）只用于关键定义/论断，且注明页码（如有）。
